# Archived LLMail experiment

This directory preserves the earlier email-specific 100-attack/20-control corpus,
its original adapter, import script, license and attribution. It is excluded from
the npm package. The earlier 113/120 result is not a general guardrail accuracy
claim and was obtained with a different question set and email-specific policy.

The active benchmark is `src/research-cases.js`: 120 authored contextual
regressions, labelled explicitly as authored rather than proven exploits.
No live tools are executed by either corpus.
